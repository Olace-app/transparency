# Test vectors

Deterministic vectors that pin the exact bytes of Olace's cryptography. All inputs are fixed constants (RFC 7748 X25519 scalars, fixed nonces, fixed test keys); nothing here is or resembles real key material.

## e2ee_vectors.json

Generated by the Go implementation (`olace-e2ee-go/cmd/genvectors`) and enforced by BOTH implementations' test suites:

- `olace-e2ee-go`: `e2ee/vectors_test.go` (the file lives at `e2ee/testdata/e2ee_vectors.json`)
- `olace-crypto-dart`: `test/e2ee_vectors_test.dart` (copy at `test/vectors/e2ee_vectors.json`)

Contents: X25519 known answers (Alice and Bob are the RFC 7748 section 6.1 keys, so the Go and Dart X25519 are checked against the RFC, not just against each other), HKDF-derived session and auth keys for both session types, canonical handshake transcripts with their HMAC tags, an identity fingerprint, and AES-256-GCM envelope decrypt vectors. Envelopes are decrypt-direction because encrypt nonces are random at run time; both implementations must accept identical wire bytes and must reject their replay.

Two independent implementations agreeing on every value is the wire-compatibility proof between the app and the daemon.

## zk_vectors.json

Generated and enforced by `olace-crypto-dart` (`test/zk_vectors_test.dart`). Pins the `zk1` backup envelope, Master Key wrap under the Recovery Key, the per-purpose HKDF derivations, the PIN vault three-stage derivation (Argon2id, harden blind, vault key, auth tag), and the Crockford recovery key format. These are the formats shipped clients have already written to user backups: the vectors changing would mean existing backups stop decrypting, so tests treat any mismatch as a defect in the code, never in the vectors.

## Updating

Vectors change only for a deliberate, versioned format change, never as part of a refactor. The flow: regenerate from the implementation that owns the vector, land the same file in this repo and in the consuming repos in the same change window, and document the wire break in the release notes of the affected repos.
